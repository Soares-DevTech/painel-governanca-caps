# 🏥 Painel de Governança e Rede CAPS - Piauí

Aplicativo em nuvem desenvolvido em Python e Streamlit para o gerenciamento, monitoramento e visualização das bases de dados da Rede de Atenção Psicossocial (CAPS) do Estado do Piauí.

## 🚀 Sobre o Projeto
Este painel centraliza o acesso a diferentes bases de dados institucionais, permitindo consulta rápida, filtragem e organização de fichas técnicas, calendários de governança e marcos legais de forma ágil e interativa na nuvem.

## 📁 Módulos Disponíveis
O painel está estruturado para alternar entre as seguintes bases de dados:
* **Rede CAPS PI:** Listagem e mapeamento das unidades e serviços nos municípios do Piauí.
* **Repositório Legal:** Documentação, portarias e normativas de referência.
* **Calendário de Governança:** Cronograma de monitoramento, reuniões e eventos institucionais.
* **Tipos de CAPS:** Especificações técnicas das modalidades de atendimento (I, II, III, i, ad).

## 🛠️ Tecnologias Utilizadas
* **Python** (Linguagem principal)
* **Streamlit** (Interface e hospedagem em nuvem)
* **Pandas** (Manipulação e leitura dos dados tabulares em `.csv`)

## 📱 Acesso Mobile (Android)
O aplicativo foi desenhado para ser responsivo. Pode ser acessado via navegador no smartphone e fixado diretamente na **Tela Inicial** do Android como um atalho rápido de aplicativo (PWA).
